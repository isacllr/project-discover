# Projeto Discover

Página de links pessoal (estilo "link na bio") feita com HTML, CSS e JavaScript puro, com alternância entre tema claro e escuro.

## Funcionalidades

- Foto de perfil e lista de links
- Botão para alternar entre modo claro e escuro (`toggleMode()`)
- Ícones de redes sociais (GitHub, Instagram, LinkedIn) via Ionicons
- Layout responsivo com fundos diferentes para desktop e mobile
- Fonte Inter (Google Fonts)

## Estrutura

```
.
├── index.html
├── style.css
├── script.js
└── assets/        # imagens, fundos e ícones (sol/lua)
```

## Como executar

Não precisa de build. Basta abrir o `index.html` no navegador, ou usar a extensão Live Server do VS Code.
